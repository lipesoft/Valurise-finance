# Planos de teste Valurise

Guarde aqui planos de cobertura dos fluxos do Valurise. Use os prompts em `.codex/prompts/` para planejar, gerar ou reparar testes. Antes de adicionar cenário autenticado, confira a seção de segurança em `docs/DESENVOLVIMENTO.md`; testes locais devem usar APIs mockadas e nunca dados financeiros de produção.
