# VALURISE Finance

Organizador financeiro pessoal, mobile-first, criado para registrar movimentações rapidamente e acompanhar saldo, orçamentos, metas, investimentos e compromissos em uma experiência de fintech moderna.

**Aplicação:** [valurise.vercel.app](https://valurise.vercel.app)

## Principais recursos

- Dashboard financeiro e lançador rápido
- Extrato, contas, cartões, categorias, metas e orçamentos
- Planejamento de recorrências e relatórios
- Tema claro/escuro, PWA e animações discretas
- Estrutura preparada para Supabase Auth, PostgreSQL e RLS

## Tecnologias

Next.js, TypeScript, Tailwind CSS, Framer Motion, Recharts, Vitest e Supabase.

## Rodar localmente

```bash
npm install
copy .env.example .env.local
npm run dev
```

Para validação, use `npm run lint`, `npm test` e `npm run build`.
